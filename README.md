# RTL-SDR V4 FT8 Skimmer

Σταθμός παρακολούθησης FT8 για όλο το HF με ένα RTL-SDR Blog V4. Σε κάθε κύκλο των 15 δευτερολέπτων ακούει άλλη ζώνη, αποκωδικοποιεί με το `jt9` του WSJT-X, σχεδιάζει τις διαδρομές σε χάρτη και, αν θέλετε, στέλνει αναφορές στο PSKReporter.

Ρύθμιση σταθμού: **SV1EEX**.

## Πώς δουλεύει

1. Ο δέκτης δουλεύει στα 960 kS/s, συντονισμένος 150 kHz κάτω από τη συχνότητα dial, ώστε η αιχμή DC να μένει μακριά.
2. Το σήμα κατεβαίνει σε ήχο USB 12 kS/s (0–3 kHz) με τρία στάδια φίλτρων και αποδεκατισμού.
3. Στο δευτερόλεπτο 14 κάθε κύκλου ο δέκτης αλλάζει ζώνη. Οι εκπομπές FT8 τελειώνουν περίπου στα 13,2 s, άρα δεν χάνεται τίποτα.
4. Ο ήχος του κύκλου γράφεται σε WAV και περνά από το `jt9 -8`.
5. Από κάθε μήνυμα βγαίνει διακριτικό και locator, απόσταση, γραμμή στον χάρτη.

**Ισοτιμία κύκλων.** Οι σταθμοί FT8 εκπέμπουν είτε σε άρτιους είτε σε περιττούς κύκλους. Με απλή εναλλαγή και άρτιο πλήθος ζωνών, κάθε ζώνη θα ακουγόταν πάντα στην ίδια ισοτιμία και θα χανόταν ο μισός κόσμος. Το πρόγραμμα μετατοπίζει τη σειρά κατά μία θέση σε κάθε γύρο, ώστε κάθε ζώνη να ακούγεται και στις δύο.

## Τι χρειάζεστε (Windows 10/11 x64)

- **.NET 10 Desktop Runtime.**
- **WebView2 Runtime** (υπάρχει ήδη στα Windows 11).
- **Οδηγός WinUSB** για το dongle, μέσω Zadig (όπως για SDR# / SDR++).
- **`rtlsdr.dll` και `libusb-1.0.dll`** από τις εκδόσεις του [rtl-sdr-blog](https://github.com/rtlsdrblog/rtl-sdr-blog/releases), δίπλα στο `RtlFt8Skimmer.exe`. Το κανονικό librtlsdr δεν ξέρει τον upconverter HF του V4.
- **WSJT-X** εγκατεστημένο. Το πρόγραμμα ψάχνει το `jt9.exe` στο `C:\WSJT\wsjtx\bin\`· αλλιώς το δείχνετε με το κουμπί «…».
- Κεραία HF στην είσοδο του V4 (ακόμη και ένα σύρμα 10–20 m δίνει αποτελέσματα).

## Χτίσιμο

```
dotnet build -c Release
dotnet run -c Release --project src/Skimmer.Wpf
```

Η ροή GitHub Actions (`.github/workflows/build.yml`) τρέχει τις δοκιμές σε Linux και βγάζει έτοιμο πακέτο Windows με το `rtlsdr.dll` του rtl-sdr-blog μέσα.

## Δοκιμές χωρίς υλικό

```
sudo apt install wsjtx
dotnet run -c Release --project tests/Skimmer.Tests
```

Η δοκιμή φτιάχνει σήματα FT8 με το `ft8sim`, τα μετατρέπει σε IQ 960 kS/s με θόρυβο 8 bit για τρεις ζώνες, και τα περνά από ολόκληρη τη μηχανή (αλλαγές ζώνης, DSP, `jt9`). Ελέγχει ότι κάθε μήνυμα αποκωδικοποιείται στη σωστή ζώνη και συχνότητα και ότι δεν περνά τίποτα σε λάθος ζώνη.

## PSKReporter

Ξεκινήστε με το «δοκιμαστικός» επιλεγμένο (θύρα 14739). Όταν βεβαιωθείτε ότι οι αναφορές εμφανίζονται σωστά, αφαιρέστε το για τον κανονικό διακομιστή. Οι αναφορές στέλνονται ανά 5 λεπτά, χωρίς διπλότυπα ανά ζώνη.

## Ρυθμίσεις

Αποθηκεύονται στο `%LOCALAPPDATA%\RtlFt8Skimmer\settings.json`.

| Ρύθμιση | Σημασία |
|---|---|
| Κέρδος | Σε HF ξεκινήστε γύρω στα 28 dB· αν βλέπετε πολλά ψευδοσήματα από σταθμούς AM, χαμηλώστε. |
| ppm | Το TCXO του V4 είναι ±1 ppm· συνήθως 0. |
| Κύκλοι/ζώνη | 1 = νέα ζώνη κάθε 15 s. Με 2, κάθε ζώνη ακούγεται σε άρτιο και περιττό κύκλο διαδοχικά. |
| Bias-T | Μόνο για ενεργή κεραία ή LNA. |
